# Frontend — лабораторная работа по Git

HTML-страница с формой отправки данных на Flask-сервер и кнопкой чтения файла `data.txt`.

## Версии

- **v1.0** — форма отправки текста на backend
- **v2.0** — добавлена кнопка загрузки содержимого `data.txt` с сервера

## Запуск

Откройте `index.html` в браузере. Backend должен быть запущен на `http://127.0.0.1:5000`.
